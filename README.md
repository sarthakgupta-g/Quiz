# Quiz
User takes quiz and finds out how many questions answered correctly

Input:
- answers

Outputs:
- correct or incorrect
- correct answer if incorrect
- total score at end

Ex:
- output: Q1
- input: 4
- output: Correct
- output: Q2
-  input: 3
- output: incorrect, correct answer is 5
- output: Q3
- input: 2
- ...
- output: Final score: 4 out of 5 correct
